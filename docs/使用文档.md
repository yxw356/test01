# 龙汇QA使用文档

## 1. 文档目标

本文档说明如何在本地或服务器上启动龙汇QA，并介绍系统的主要使用流程，包括登录、用户管理、权限配置、知识分类、数据清洗、文件上传、断点续传、知识库问答和运行监控。

如果只是日常本机体验，优先按“本地快速启动”执行。如果要部署到正式环境，建议使用MySQL、Redis、MinIO、Kafka、Elasticsearch等完整中间件。

## 5. 手工启动完整环境

### 5.1 启动中间件

在项目根目录执行：

```bash
cd /Users/lhrzp/test01
docker compose -f docs/docker-compose.yaml up -d
```

检查：

```bash
docker compose -f docs/docker-compose.yaml ps
```

需要看到MySQL、Redis、MinIO、Kafka、Elasticsearch都处于运行状态。

### 5.2 启动向量模型

向量模型用于上传文档后的Embedding。推荐单独起一个OpenAI兼容服务，例如vLLM bge-m3：

```bash
vllm serve BAAI/bge-m3 \
  --task embed \
  --host 127.0.0.1 \
  --port 8001 \
  --api-key vllm_api_key_12345 \
  --served-model-name bge-m3
```

验证：

```bash
curl -s -H "Authorization: Bearer vllm_api_key_12345" \
  http://127.0.0.1:8001/v1/models
```

### 5.3 配置对话模型

系统通过OpenAI兼容协议调用对话模型。当前默认使用DeepSeek云端接口，密钥通过环境变量注入：

```bash
export DEEPSEEK_API_URL=https://api.deepseek.com
export DEEPSEEK_API_MODEL=deepseek-v4-flash
export DEEPSEEK_API_KEY=你的密钥
```

也可以改成本地vLLM或Ollama，只要提供兼容`/v1/chat/completions`的接口。

### 5.4 启动后端

本地体验推荐使用`local`配置，它使用文件型H2数据库，重启后不会丢失上传元数据：

```bash
cd /Users/lhrzp/test01
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export PATH=/opt/homebrew/opt/openjdk@17/bin:$PATH
mvn spring-boot:run -Dspring-boot.run.profiles=local
```

后端启动成功后，浏览器访问`http://127.0.0.1:8081/`会返回健康信息。

正式环境可以不加`local` profile，使用`application.yml`里的MySQL配置。

### 5.5 启动前端

```bash
cd /Users/lhrzp/test01/frontend
pnpm install
pnpm dev
```

打开：

```text
http://127.0.0.1:9527
```

## 7. 用户和部门管理

### 7.1 角色说明

| 角色 | 可以做什么 |
| --- | --- |
| 超级管理员 | 管理所有账号、部门、知识、权限和运行监控 |
| 知识管理员 | 维护公共知识，上传公共文档，重清洗和重索引公共知识 |
| 部门负责人 | 维护本部门知识，创建本部门成员账号 |

### 7.2 添加账号

超级管理员：

1. 进入“用户管理”。
2. 点击“新增用户”。
3. 填写用户名、密码、角色、所属部门。
4. 保存。

部门负责人：

1. 进入“用户管理”。
2. 点击“新增用户”。
3. 只能创建本部门的部门成员。
4. 保存。

系统已关闭外部开放注册，普通用户不能自行注册账号。

### 7.3 分配部门

用户需要绑定主部门或组织标签。部门知识的可见范围会根据该字段判断，配置错误会导致看不到部门知识或错误授权。

## 10. 数据清洗规则

数据清洗用于提升检索和问答质量。上传文档后，系统会先提取文本，再按清洗规则处理，然后切分并向量化。

### 10.1 默认清洗内容

| 规则 | 作用 |
| --- | --- |
| 统一换行 | 避免Windows、macOS、Linux换行差异 |
| 规范空白符 | 清除不可见空格、全角空格等干扰 |
| 压缩空格 | 避免大量连续空格影响切分 |
| 去除行首行尾空白 | 让文本更规整 |
| 合并空行 | 降低噪声 |
| 删除重复行 | 去掉PDF页眉页脚重复内容 |
| 正则删除噪声行 | 删除页码、目录、分隔线等 |

### 10.2 编写清洗规则建议

保持保守，优先删除明确无业务价值的内容，例如：

```text
^第\s*\d+\s*页\s*/\s*共\s*\d+\s*页$
^Page\s+\d+\s+of\s+\d+$
^\d+\s*/\s*\d+$
^[-—_=]{3,}$
^目录$
^\.{5,}$
```

不要轻易删除包含金额、日期、比例、编号、合同条款编号的行，因为这些信息经常是问答最需要的依据。

### 10.3 重新清洗

当你发现预览文本里有大量页眉页脚、乱码、目录或重复内容时：

1. 进入“知识资产”。
2. 找到目标文件。
3. 配置或选择新的清洗规则。
4. 点击“重新清洗”。
5. 等待索引状态变为可检索。

## 11. 上传知识库文件

### 11.1 支持格式

当前支持：

```text
pdf, doc, docx, xls, xlsx, ppt, pptx, txt, rtf, md,
odt, ods, odp, html, htm, xml, json, csv, epub,
pages, numbers, keynote
```

不支持图片、音频、视频、压缩包、可执行文件等无法稳定提取文本的格式。

### 11.2 上传大小

默认最大文件大小为200MB。前端和后端都按这个限制处理。

### 11.3 上传公共知识

适合公司级制度、通用流程、所有人都能访问的知识。

1. 进入“知识资产”。
2. 点击“上传”。
3. 选择“公共知识”。
4. 选择分类和清洗规则。
5. 选择文件并上传。
6. 等待上传状态变为“已完成”，索引状态变为“可检索”。

公共知识通常由知识管理员或超级管理员维护。

### 11.4 上传部门知识

适合部门内部资料、项目资料、部门流程。

1. 进入“知识资产”。
2. 点击“上传”。
3. 选择“部门知识”。
4. 选择所属部门、分类、清洗规则。
5. 选择文件并上传。
6. 等待索引完成。

部门知识通常由部门负责人维护。

### 11.5 断点续传

上传大文件中断后：

1. 在知识资产列表找到“上传中断”的文件。
2. 点击“续传”。
3. 重新选择同一个文件。
4. 系统会校验MD5，匹配后继续上传缺失分片。

如果选择了不同文件，系统会拒绝续传，避免把不同文件合并到同一条记录。

## 12. 文件预览、下载和管理

知识资产列表中可以进行：

- 预览：查看解析后的文本或文件内容。
- 下载：下载原始文件。
- 删除：删除文件元数据和相关索引。
- 重新清洗：修改清洗规则后重新处理文本。
- 重新索引：重新生成向量和ES索引。

如果预览出现乱码，常见原因有：

| 原因 | 处理方式 |
| --- | --- |
| 文件本身是扫描件PDF | 需要OCR能力，当前主要是文本解析 |
| 文件编码异常 | 转成UTF-8文本或另存为标准Office/PDF格式 |
| 文件格式实际与扩展名不一致 | 使用正确格式重新导出 |
| Tika解析不理想 | 尝试转成PDF、docx、xlsx或txt再上传 |

## 13. 使用聊天助手

### 13.1 普通提问

进入“聊天助手”，输入问题即可。系统支持常规问题，例如：

```text
你是谁？
你能做什么？
```

### 13.2 知识库问答

提问企业内部资料时，建议写清楚对象、范围和需要的答案类型：

```text
报销制度里差旅住宿标准是多少？
测试部门的项目交付流程有哪些步骤？
请根据培训资料总结新员工入职前三天需要完成的事项。
```

### 13.3 查看来源

回答下方会显示来源入口。来源默认收起，点击后可以查看参考文档和片段。若没有来源，说明本轮没有检索到可靠知识库依据，或问题属于常规问答。

### 13.4 提升回答准确率

如果回答不准确，优先检查：

1. 文件是否已经索引完成。
2. 问题涉及的文档是否在当前用户权限范围内。
3. 文档预览文本是否正常。
4. 是否需要调整清洗规则。
5. 是否需要重新索引。
6. 问题是否过于笼统，缺少关键词或部门范围。

## 16. 常见问题

### 16.1 登录后Network Error

检查：

```bash
curl http://127.0.0.1:8081/
```

如果后端没启动，先启动后端。如果前端地址或代理配置不对，确认前端访问的是`127.0.0.1:8081`后端。

### 16.2 上传后重启数据没了

原因通常是使用了内存H2数据库`jdbc:h2:mem`。当前本地配置已改为文件型H2：

```text
jdbc:h2:file:./data/PaiSmart
```

历史已经丢失的内存库记录无法直接恢复，需要重新上传，或后续通过MinIO/ES反向补元数据。

### 16.3 上传完成但不能问到内容

检查顺序：

1. 运行监控里Kafka是否积压。
2. 运行监控里ES是否可用。
3. ES知识库索引数量是否增加。
4. 向量模型是否可用。
5. 文件索引状态是否为“可检索”。
6. 当前用户是否有该文件权限。

### 16.4 预览乱码

优先确认文件是否为扫描件、加密文件、异常编码文件或扩展名错误文件。必要时另存为标准PDF、docx、xlsx或UTF-8文本后重新上传。

### 16.5 Maven打包报Lombok错误

检查`mvn -version`。如果Java版本不是17，切换JDK：

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home
export PATH=/opt/homebrew/opt/openjdk@17/bin:$PATH
mvn -q -DskipTests package
```

### 16.6 运行监控显示模型不可用

检查：

```bash
curl http://127.0.0.1:8001/v1/models
curl http://127.0.0.1:8000/v1/models
```

如果使用DeepSeek云端对话模型，还要确认环境变量已设置，并且网络可以访问模型服务。

## 18. 知识库分区使用

知识库页面现在按“知识库分区”展示：

| 分区 | 说明 |
| --- | --- |
| 公共知识库 | 全员可见的制度、公告、通用资料 |
| 部门知识库 | 每个部门单独一个块，例如人事部知识库、财务部知识库 |
| 当前块文件 | 点击某个块后，下方文件表格只显示该块内文件 |

常用操作：

1. 在知识库页面点击公共知识库或部门知识库块。
2. 下方文件表格自动切换到当前块。
3. 可以拖动知识库块调整顺序，顺序会保存在当前浏览器。
4. 在某个块中点击上传，上传弹窗会自动带出公共或部门范围。
5. 进入聊天助手后，当前知识库块会作为问答范围，引用来源会优先限制在该块内。
